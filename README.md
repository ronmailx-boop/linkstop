# LinkStop

אפליקציית PWA (Progressive Web App) לריכוז קישורים ששיתפת לעצמך מוואטסאפ,
פייסבוק, יוטיוב וכרום — כדי שלא יאבדו בתוך הודעות ושיחות. במקום לשמור
קישור בהודעה "לעצמי" ולשכוח ממנו, LinkStop שומר כל קישור ככרטיס עם
כותרת, תמונת תצוגה מקדימה ותיאור, בדיוק כמו התצוגה המקדימה שרואים
בוואטסאפ.

## מה זה עושה

- **הוספת קישור ידנית** — הדבקת קישור בטופס באפליקציה.
- **שיתוף ישיר מהמכשיר** — דרך תפריט השיתוף באנדרואיד (מוואטסאפ, פייסבוק,
  כרום ועוד) ישירות לתוך LinkStop, בעזרת מנגנון ה-`share_target` של ה-PWA.
- **שליפת כותרת ותמונה אוטומטית** — לכל קישור שנשמר (כולל טיפול ייעודי
  בקישורי יוטיוב דרך YouTube oEmbed, ובקישורי פייסבוק שדורשים זיהוי
  מיוחד כדי לעקוף חסימות).
- **מחיקה עם אישור** — הסרת קישורים שכבר לא רלוונטיים.
- **התקנה כאפליקציה** — ניתן להוסיף למסך הבית באנדרואיד ולהשתמש בה כמו
  אפליקציה רגילה (PWA מלא, כולל אייקון ומסך פתיחה).

## למי זה מיועד

לשימוש אישי — שמירת קישורים שרוצים לחזור אליהם מאוחר יותר (סרטונים,
מאמרים, פוסטים), בלי צורך לחפש אותם מחדש בתוך היסטוריית הצ'אטים.

## טכנולוגיה

- **Frontend**: HTML/CSS/JavaScript סטטי (ללא framework), Mobile-First
  ו-RTL מלא, מוגש דרך GitHub Pages.
- **אחסון**: `localStorage` בדפדפן — ללא צורך בהתחברות או חשבון משתמש.
- **Backend**: Supabase Edge Function (`fetch-metadata`) שאחראית על
  שליפת כותרת/תמונה/תיאור מהקישור שנשמר (עוקפת מגבלות CORS שיש בדפדפן
  לביצוע קריאה ישירה לאתרים חיצוניים).
- **Service Worker** — לצורך התקנה כ-PWA (network-first, ללא cache מלא
  של תוכן).
